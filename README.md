# 🖥️ 우테코 프리코스 2주차 - 자동차 경주
- 기능 요구 사항에 기재되지 않은, 스스로 판단한 부분은 **볼드체** 사용

## 📖 프로젝트 개요
- 간단한 자동차 경주 게임 구현
- 주어진 횟수 동안 n대의 자동차는 전진 또는 정지
  - **자동차는 2대 이상, 7대 이하여야 함**
- 각 자동차에 이름 부여 가능, 전진하는 자동차를 출력할 때 자동차 이름 출력
  - 자동차 이름은 쉼표(,)를 기준으로 구분하며 5자 이하만 가능
  - **자동차 이름은 영어로만 구성되어야 함**
  - **자동차 이름은 중복될 수 없음**
- 사용자는 자동차의 전진 또는 정지를 시도할 횟수 입력
  - **횟수는 1-30 사이의 정수여야 함**
- 자동차는 0-9 사이의 무작위 값 하나가 4 이상일 경우 전진
- 자동차 경주 게임을 완료한 후 우승자 출력
  - 우승자는 한 명 이상일 수 있으며, 여러 명일 경우 쉼표(,)를 이용해 구분
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 종료

## ⌨️ 입출력 요구 사항
### 입력
- 경주할 자동차 이름
  - 이름은 쉼표(,) 기준으로 구분
  - 자동차 이름이 비어있거나 5자를 초과할 경우 에러 발생
  - **자동차 이름에 공백이 존재할 경우 에러 발생**
  - **자동차 이름이 영어로만 구성되어 있지 않을 경우 에러 발생**
  - **자동차가 2대 미만, 7대 초과일 경우 에러 발생**
  - **자동차 이름이 중복될 경우 에러 발생**
- 시도할 횟수 
  - int 범위를 벗어난 입력이 들어올 경우 에러 발생
  - **횟수가 1-30 사이의 정수가 아닌 경우 에러 발생**

### 출력
- 차수별 실행 결과
  - 자동차 이름과 현재 전진 상태를 출력
  - 예시: `pobi : --`
- 우승자 안내 문구
  - 단독 우승자 안내 문구 예시: `최종 우승자 : pobi`
  - 공동 우승자 안내 문구 예시: `최종 우승자 : pobi, jun`

### 실행 결과 예시
```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
시도할 횟수는 몇 회인가요?
3

실행 결과
pobi : -
woni : 
jun : -

pobi : --
woni : -
jun : --

pobi : ---
woni : --
jun : ---

최종 우승자 : pobi, jun
```

## 📜 프로그래밍 요구사항
- JDK 21 버전에서 실행 가능해야 한다.
- 프로그램 실행의 시작점은 `Application`의 `main()`이다.
- `build.gradel` 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- 프로그램 종료 시 `System.exit()`를 호출하지 않는다.
- 프로그래밍 요구 사항에서 달리 명시하지 않는 한 파일, 패키지 등의 이름을 바꾸거나 이동하지 않는다.
- 자바 코드 컨벤션을 지키면서 프로그래밍한다.
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다. 
  - 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
- 3항 연산자를 쓰지 않는다. 
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- JUnit 5와 AssertJ를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
