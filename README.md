# 🖥️ 우테코 최종 미션 연습 - [자동차 경주]

- 기능 요구 사항에 기재되지 않은, 스스로 판단한 부분은 **볼드체** 사용

## 📖 프로젝트 개요

- 초간단 자동차 경주 게임 구현
- 각 자동차에 이름 부여 가능
    - 자동차 이름은 쉼표(,)를 기준으로 구분, 5자 이하만 가능
- 사용자는 몇 번의 이동을 할 것인지 입력
- 자동차가 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후, 무작위 값이 4 이상일 경우
- 자동차 경주 게임 완료 후 우승자 발표
    - 우승자가 여러 명일 경우 쉼표(,)를 이용해 구분
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고 애플리케이션 종료

## ⌨️ 입출력 요구 사항

### 입력

- 경주할 자동차 이름
    - 빈 문자열이 입력된 경우 예외 발생
    - 영어, 쉼표를 제외한 문자가 들어간 경우 예외 발생
    - 자동차 이름이 1자 미만, 5자 초과일 경우 예외 발생
- 시도할 횟수
    - 빈 문자열이 입력된 경우 예외 발생
    - 숫자를 제외한 문자가 입력된 경우 예외 발생
    - 숫자가 int 범위를 초과한 경우 예외 발생
    - 숫자가 1 미만일 경우 예외 발생

### 출력

- 각 차수별 실행 결과

```
pobi : --
woni : ----
jun : ---
```

- 단독 우승자 안내 문구

```
최종 우승자 : pobi
```

- 공동 우승자 안내 문구

```
최종 우승자 : pobi, jun
```

### 실행 결과 예시

```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)

시도할 횟수는 몇회인가요?
5

실행 결과
pobi : -
woni : 
jun : -

```

## 📜 프로그래밍 요구사항

### 라이브러리

- `camp.nextstep.edu.missionutils`에서 제공하는 `Randoms` 및 `Console` API를 사용하여 구현
    - Random 값 추출은 `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInRange()`를 활용
    - 사용자가 입력하는 값은 `camp.nextstep.edu.missionutils.Console`의 `readLine()`을 활용
- 사용 예시
    - 0에서 9까지의 정수 중 한 개의 정수 반환

```
Randoms.pickNumberInRange(0,9);
```

## ✅ 구현 기능 목록

### 자동차 이름 입력

```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni,jun
```

- 사용자에게 입력값 요청
    - `camp.nextstep.edu.missionutils.Console`의 `readLine()` 활용
- 입력값 검증: 잘못된 값일 경우 `IllegalArgumentException` 발생 및 재입력 요청
    - 빈 문자열이 입력된 경우 예외 발생
    - 영어, 쉼표를 제외한 문자가 들어간 경우 예외 발생
    - 자동차 이름이 1자 미만, 5자 초과일 경우 예외 발생

### 시도할 횟수 입력

```
시도할 횟수는 몇회인가요?
5
```

- 사용자에게 입력값 요청
    - `camp.nextstep.edu.missionutils.Console`의 `readLine()` 활용
- 입력값 검증: 잘못된 값일 경우 `IllegalArgumentException` 발생 및 재입력 요청
    - 빈 문자열이 입력된 경우 예외 발생
    - 숫자를 제외한 문자가 입력된 경우 예외 발생
    - 숫자가 int 범위를 초과한 경우 예외 발생
    - 숫자가 1 미만일 경우 예외 발생

### 자동차 이동

- 랜덤 값에 따라 자동차가 이동할지 말지 결정
    - `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInRange()`를 활용
    - 랜덤 값이 4 미만일 경우 이동 X
    - 랜덤 값이 4 이상일 경우 이동

### 실행 결과 출력

```
실행 결과
pobi : -
woni : 
jun : -
```

- 각 이동마다 자동차의 현재 위치 출력

### 최종 우승자 결정

- 가장 많이 이동한 자동차를 우승자로 결정
    - 공동 우승자 존재 가능

### 최종 우승자 출력

```
최종 우승자 : pobi, jun
```
